🎬 Stream & Install Guide

1
In OBS, Sources panel → click + → Browser Source
2
Set URL: file:///C:/path/to/prism-vtuber.html?stream (or host via npx serve . → http://localhost:3000/prism-vtuber.html?stream)
3
Width: 1920, Height: 1080 — Check "Use custom frame rate" → 30fps
4
Click Interact on the source to grant camera permission the first time.
5
The ?stream param hides all UI — only the face/avatar canvas shows. Remove it to keep the full PRISM UI visible in OBS.
Tip: Use PRISM's Game Overlay mode with Chroma Green background, then add a Chroma Key filter in OBS to make the background transparent.
1
In Streamlabs → Scene Editor → + → Browser Source
2
Paste the file path or localhost URL. Append ?stream for UI-less output.
3
Set resolution 1920×1080. Right-click source → Transform → Fit to Screen.
4
For face-cam corner overlay: resize + position in corner. Use Chroma Key filter with PRISM's green background.
Chroma Key: Enable Game Overlay → Chroma G in PRISM, then in Streamlabs add Chroma Key filter → select color #00FF00.
1
PRISM runs inside OBS as a Browser Source. OBS then streams to YouTube via RTMPS.
2
OBS: Settings → Stream → Service: YouTube → RTMPS. Paste your stream key from YouTube Studio.
3
YouTube Studio → Go Live → copy stream key → paste in OBS → click Start Streaming.
Direct recording: PRISM's built-in ⏺ REC button captures to .webm locally. Upload directly to YouTube.
1
Install OBS Studio 26+ (Virtual Camera is built-in). Older versions need the OBS-VirtualCam plugin.
2
Add PRISM as Browser Source in OBS (see OBS tab). Make sure it's active.
3
OBS → Controls panel → Start Virtual Camera. This creates "OBS Virtual Camera" as a system camera device.
4
In Zoom, Teams, Discord, Meet — select OBS Virtual Camera as your camera. Your PRISM avatar appears!
macOS: Use Reincubate Camo or mmhmm as virtual camera alternatives. Mobile: Use NDI Tools to bridge to PC pipeline.
1
Discord: Enable OBS Virtual Camera → Discord Settings → Voice & Video → select "OBS Virtual Camera".
2
Twitch/Kick: OBS → connect via RTMP key from your dashboard → Start Streaming. PRISM is your scene layer.
3
Steam Broadcasting: Enable in Steam Settings → Broadcasting. Select OBS Virtual Camera as your webcam source.
4
TikTok Live: Use OBS + TikTok LIVE Studio plugin, or StreamYard with PRISM as browser source via localhost.
Quick local server: Install Node.js → run npx serve . in the folder with this file → use http://localhost:3000/prism-vtuber.html?stream
